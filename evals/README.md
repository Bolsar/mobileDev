# Evals

Run these by hand. Copy the repo into a sample project as `.mobile-agent/`, paste the prompt into the tool, and tick the checklist. Run in Claude Code plus at least one other tool (Codex or Cursor).

A scenario passes when every **must** item is ticked.

## Format
```
### <id> — <title>
Requester: Business Owner | Non-mobile Developer | Mobile Developer
Prompt: "<exact prompt>"
Must:
- [ ] …
Must not:
- [ ] …
```

## Files
One file per Skill Group, added in phase 2: `engineering.md`, `design.md`, `collaboration.md`, `product.md`, `release.md`. `mindset.md` covers the cross-cutting behavior. `stacks.md` covers the Stack Packs (phase 3).
